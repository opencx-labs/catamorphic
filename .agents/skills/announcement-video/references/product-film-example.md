# Product film composition example

This is a reusable example, not a claim about a shipped feature.

A short single-feature silent desktop film can establish a real project, move into its working document, reveal a useful app or visual workflow, and settle on the complete workspace. Capture genuine transitions. Use prepared, non-sensitive project content and identify that setup in the brief.

| Review finding | Reusable correction |
| --- | --- |
| The opening moves too quickly | Hold the first meaningful interface for three seconds. |
| The edit feels like slides | Keep one spatial composition and connect real actions. |
| The product blends into its surroundings | Use restrained shadow and tonal separation. |
| A floating panel obscures the work | Inspect the full motion path and keep important content clear. |
| Captions overwhelm the interface | Use short bottom-left copy without a backing panel. |
| Text is unreadable in the hero | Reframe toward the important region and verify embedded playback. |
| The wordmark looks approximate | Use the actual brand asset or website wordmark treatment. |
| The outro disappears too soon | Hold the benefit long enough to read at normal speed. |

Preserve the accepted palette and copy across revisions. Never substitute an invented interface for footage of the real app.
