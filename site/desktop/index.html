// what it is

One place for the whole loop

Read, think, direct, judge, all without leaving. The surfaces agents need to do real work are the same surfaces you use every day.

Real work surfaces

Web tabs with your logins and profiles, real terminals (Ghostty's engine), an editor, and chats: all first-class tabs in one workspace, tileable side by side. Agents and you share the same surfaces.

Bring your own agents

Claude Code, Codex, and API models run side by side as named agents, on your accounts, your keys, your existing logins. Switch the agent or its effort per chat from the command palette. No middleman subscription.

Watchable, interruptible agents

Agent-driven tabs and terminals stay visible with a quiet accent ring, and every page action flashes on the element it touches. One click takes the surface over; the agent notices and adapts instead of fighting you.

Review what matters, code or prose

Nothing an agent does is hidden: pull up diffs for code or track-changes for writing whenever a change deserves scrutiny. Skim the routine, dig into the critical, redirect the agent from the diff. Built for writers and researchers as much as developers. In progress.

Notes and projects are files

A project is a folder you can see in Finder. Notes are markdown inside it. Config is JSON you can edit by hand, or ask an agent to. Nothing hides in an opaque store; leave any time with everything. Notes in progress.

Sync on git, cloud of your own

Connect your GitHub and your projects, notes, and settings sync between devices; it's all files in git underneath. Connect your Cloudflare account for a private cloud we host nothing of. On the roadmap.

// how a session goes

Delegate without disappearing

The point isn't autonomy theater. It's real work, visible, with you in the loop exactly where you want to be.

1

Ask, from anywhere

Cmd+T opens the palette: search, navigate, or just type what you want done. Long input becomes a message to an agent.

2

Watch it work

The agent opens tabs, runs terminals, edits files. Each surface chips onto its chat, live and visible, never hidden.

3

Steer when you want

Take over any surface mid-task. Queue follow-ups while the agent runs. Answer its questions when it's genuinely blocked.

4

Judge, then land it

Skim what the session produced, dig into the changes that matter (code and prose alike), and commit when you're satisfied. Scrutiny where you choose, not a toll gate on every line.

workspacelive

01 / your machine

Local-first, by construction

State lives on your disk. Profiles keep work and life separate: each owns its projects, logins, theme, shortcuts, and agent roster.

02 / your rules

Everything is configurable, even by your agents

Keybindings, sidebar, and theme are plain files, watched live. Ask an agent to "make the accent purple" or "add a Docs section" and it edits the same files you would.

03 / honest boundaries

Contained, not omnipotent

Agents run under real trust boundaries: sandboxed execution, permission scopes, and credentials that are never silently agent-reachable. Control you can see, limits you can set.
