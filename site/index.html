All your work in one place: documents, data, code, automations, and apps live together in projects you own, and agents help on the same surfaces you use: web tabs with your logins, terminals, editors. // the idea

Built to get real work out of agents

Not a chat window with tools bolted on. A workspace where agent output becomes finished work: pages browsed, commands run, files shipped, history kept.

Projects hold any kind of work

A project is a folder that can hold documents, notes, data, plans, code, automations, and apps, in any mix. Ask for your first automation and the workspace for it appears; until then, your files are all there is.

Real work, real surfaces

Agents browse in tabs that carry your logins, run commands in real terminals, and edit real files. The same surfaces you use, so what they produce is the work itself, not a transcript of it. Take any surface over with one click.

Tracked like code, without the ceremony

Every project is a git repository underneath. Agent turns land as checkpoints, linked projects sync with GitHub in the background, and agents can open pull requests. You never have to see git; it is all there when you want it.

// one engine, four faces

An app you live in, an engine you embed

The same open-source engine powers a desktop workspace for people, and an embeddable framework that puts workflows, apps, and a working copilot inside your own product. The desktop app is the framework's reference implementation.

Catamorphic Desktop

A local-first workspace where your agents browse, run terminals, edit, and research beside you. Projects for any kind of work, git-native tracking without the ceremony, and a real dev shell when you want one. In active development, polished for daily use.

Workflows

Durable automations your users build with AI inside your product: TypeScript in git, rendered as a visual graph anyone can read, executed on Postgres with retries, pauses, signals, and batches. Triggered by events in your product, callable by agents as tools.

Apps

Real frontends your users build on top of their workflows: sandboxed, wired through a typed contract, with a polished UI kit, persistent per-user storage, and MCP Apps interop. The agent writes both the UI and the logic behind it.

Copilot

Everything around your product's agent, already built: durable sessions, drop-in chat surfaces, skills, tools, and sandboxed execution. Plug in your agent and your users have a copilot that builds workflows and apps for them.

// what people build with it

Four shapes the same engine takes

One substrate, very different days. These are the uses Catamorphic is built around.

The company brain

One shared project as the team's workspace: the documents, the data, the agents that know your domain, and the internal apps that act on it, all in a repo that syncs through GitHub. New teammates and new agents read the same files and inherit the same context.

Daily-driver development

Claude Code and Codex beside real terminals, an editor, worktree and PR views, and a browser, in one window. Your repo's CLAUDE.md, skills, and settings work exactly as they do in the CLI. The desktop app is built to be lived in.

A copilot in your product

Embed the engine and your users get an agent that does real work inside your product: it answers from your skills, calls the tools you allow, and builds workflows and apps on request. The copilot framework is the plumbing, yours is the product.

Internal tools, built by asking

Describe the dashboard or the back-office tool you need; an agent writes the workflows and the frontend together, in one project, in git. Durable runs behind every button, a sandboxed app in front, and no builder UI to learn.

01 / local-first

Files you can leave with

Projects are ordinary folders, notes are markdown, config is JSON you can open in any editor. Delete Catamorphic and your work is still yours, intact.

02 / bring your own

Agents, models, and clouds

Run Claude Code, Codex, and API models side by side on your own accounts and keys. Connect your GitHub and linked projects sync in the background, over infrastructure that is yours.

03 / free & open

No tiers, no meters

Permissively licensed open source. Sustainable because you bring your own infrastructure: there is no server bill for us to pass on to you.
