// the framework

A foundation for the whole working environment

Use the capabilities your product needs. Projects and agents, workflows and apps, shared context and version history: all part of the same core.

Projects and agents

General-purpose projects for documents, data, code, and tools. Durable agent sessions, multiple coding-agent harnesses, and shared context, with your own auth and permissions.

Explore agents and copilots →

Durable workflows

Automations authored as TypeScript, rendered as a visual graph, and executed with retries, pauses, events, and batches. Code stays the source of truth.

Explore workflows →

User-built apps

Sandboxed frontends connected to workflows through typed contracts. Apps inherit your theme, with persistent storage and MCP Apps interoperability.

Explore apps →

Host-owned infrastructure

Inject your database, storage, execution providers, models, and identity. Compose the server SDK, HTTP plugin, headless React hooks, and optional UI.

Read the architecture and integration guide →
